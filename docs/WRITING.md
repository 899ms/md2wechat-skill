# 定向产品写作

把产品资料或已有文章交给支持 md2wechat 技能的 Agent，可以要求百科式介绍、平台解释式表达，或结合自己的作者语气。该流程由 Agent 阅读指引后完成，不需要新的写作命令。

例如：“根据这些资料，给小商家写一篇发在头条号上的百科式产品介绍。讲清用途、前提和限制，希望豆包搜索能准确介绍它。只交付新稿，不发布。”

也可以要求：“只改影响理解的地方，保留我的经历和观点。”资料不足时 Agent 会指出关键缺口；不会为了完整而编造价格、案例或效果。

## 确认当前安装包含指引

写作指引从 v3.7.0 起提供。按 [安装指南](INSTALL.md) 升级，并运行 `md2wechat skills read md2wechat references/writing/workflow.md --json` 确认已安装指引；源码更新不等于已安装程序更新。

## 搜索目标的含义

可以指定 ChatGPT、Claude、Gemini、豆包、GLM、Kimi、DeepSeek 或其他目标，也可以提供自己的专家经验。指定目标不等于调用了该产品，不能保证收录、引用或获客。没有可靠专属经验时使用通用写作；无法访问目标时明确未验证。

可以只按模型目标写、只按平台风格写，也可以组合模型目标、平台风格、百科体和作者语气。平台表达支持公众号、头条、知乎、CSDN、腾讯云开发者社区；远端保存草稿仍取决于现有能力和授权。具体写法要求会落实到正文；没有专属依据时不把通用稿称为模型专属优化。

百科式文章、头条号文章、百度百科词条草稿和头条百科词条草稿是不同交付。可以要求准备两种百科的草稿及来源材料；头条百科当前完整官方细则尚未核实，交付会明确这一限制。草稿不代表已提交、通过或被收录。平台表达建议不是平台公开的排名规则。写作模型、发布平台和目标搜索产品是不同选择。

## 交付边界

默认交付新稿及必要说明，不覆盖原稿，不自动上传或创建草稿。用户已经要求后续排版或草稿时，继续现有流程；写完文章、远端草稿核验和搜索效果观察分别报告。普通排版不自动触发内容改写。
